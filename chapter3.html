Chapter 3

        Concept of Software
        A set of programs written for a computer to perform a particular task is called software. Software acts 
        as an interface between the user and the computer hardware. Without it, hardware is completely useless. 
        Software divides broadly into system software, which manages hardware resources, and application software, 
        which helps users perform specific jobs like word processing or browsing. System software includes 
        the operating system, language processors like compilers, interpreters, and assemblers, and utility 
        programs like antivirus tools. Application software can be tailored specifically for an organization as 
        customized software or sold broadly as packaged software like web browsers or office suites.

        Concept of Operating System
        An operating system acts as an interface between user and hardware. The operating system (OS) is the 
        primary system software that controls all overall computer operations. Major functions include process 
        management, memory allocation, file handling, and device control. It ensures that different programs run 
        smoothly without interfering with one another. Operating systems handle crucial background duties like 
        checking device status, loading application files into RAM, managing peripheral inputs and outputs, and 
        protecting system resources through user authentication and error-handling routines.

        Windows Operating System
        Windows is a GUI-based operating system developed by Microsoft. Microsoft Windows uses a graphical user 
        interface with visual elements like icons, windows, and menus. Tools like File Explorer help manage files 
        and folders, while Device Manager helps configure and control hardware components. Windows supports 
        multitasking, allowing users to run multiple applications simultaneously, and utilizes a plug-and-play 
        architecture that automatically detects and installs drivers for newly attached hardware peripherals.

        Open Source and Mobile Operating System
        Linux is an open-source operating system inspired by UNIX. Open-source operating systems allow users to view,
        modify, and distribute source code freely, with popular Linux distributions including Ubuntu and Fedora. This
        collaborative model contrasts with proprietary systems, encouraging global developer communities to enhance
        security, optimize performance, and eliminate system bugs. Meanwhile, mobile operating systems like Android and 
        iOS power modern handheld smartphones and tablets, relying heavily on energy-efficient designs, touch-optimized 
        graphical user interfaces, and built-in sensors like GPS and accelerometers.
